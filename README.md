# Monitoria de Estrutura de Dados 2

Este repositório reúne os materiais de apoio utilizados durante a Monitoria de Estrutura de Dados 2 do IFPE. O conteúdo contempla exercícios, resoluções, implementações e materiais complementares, com o objetivo de auxiliar os estudantes no estudo dos conceitos teóricos e na aplicação prática dos conteúdos abordados na disciplina.

Serão realizados encontros semanais com a turma, destinados à discussão dos conteúdos, resolução de exercícios, implementação de algoritmos e esclarecimento de dúvidas. As gravações dos encontros e aulas serão disponibilizadas no YouTube para consulta posterior.

Este repositório possui caráter complementar e não substitui os materiais oficiais, as aulas ou as orientações do professor responsável pela disciplina.
